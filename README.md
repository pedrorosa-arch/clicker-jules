# Cookie Clicker Web Application

A simple, responsive interactive web application featuring a centered clickable cookie and a click counter.

## Project Structure

- `index.html`: The markup and styling for the user interface.
- `script.js`: Interactive JavaScript logic, including click handling, animations, and cookie persistence.

## Features

- **Interactive Cookie Graphic**: Styled using modern CSS gradients, shadows, and chocolate chips.
- **Click Counter**: Increments every time the cookie is clicked, with bounce animation feedback and a floating `+1` indicator.
- **Cookie-based Persistence**: Stores the click count in a browser cookie (`document.cookie`) so your progress is saved across page reloads.
- **Reset Button**: Allows users to reset the counter back to zero anytime.
- **Responsive & Clean UI**: Centered design with smooth hover/active state transitions.

## How to Run

1. Open `index.html` in any web browser (or serve it via a local HTTP server).
2. Click on the cookie to increase your score!
